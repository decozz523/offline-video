# Sea Louder — офлайн-видео по ссылке

Вставляешь ссылку → файл сохраняется на компьютер → смотришь без интернета.

## Как запустить

1. Двойной клик по **`start.bat`** (или `python server.py` в терминале).
2. Откроется браузер на `http://127.0.0.1:8756/`.
3. Вставь ссылку и нажми **«Сохранить видео»**.

Файлы падают в папку **`downloads`** рядом с проектом. Ниже на странице есть блок
**«Мои загрузки»** — там видно всё скачанное, его можно играть встроенным плеером
даже без интернета.

## Почему нужен сервер

Браузер не может сам скачать видео с YouTube / TikTok: эти сайты отдают
только потоковый плеер, а не mp4, и любой сторонний API блокируется политикой CORS.
Поэтому скачиванием занимается маленький локальный сервер на Python — он вызывает
`yt-dlp`, склеивает видео со звуком (через `ffmpeg`) и кладёт готовый файл в `downloads`.

Интернет нужен только в момент скачивания. После этого файл играется офлайн.

## Что нужно на компьютере

| Компонент | Зачем | Проверить |
|---|---|---|
| Python 3.11 | сам сервер (`server.py`) | `python --version` |
| yt-dlp | качает и разбирает видео | `python -m yt_dlp --version` |
| ffmpeg | склеивает видео+звук в один mp4 | `ffmpeg -version` |

Установка на новом компьютере:

```powershell
python -m pip install -U yt-dlp
winget install Gyan.FFmpeg
```

Статус всех трёх видно на странице: `http://127.0.0.1:8756/api/health`.

## Режимы скачивания

- **⬇ Сохранить видео** — лучшее доступное качество в mp4 (или выбери предел в списке HD).
- **🎵 Сохранить аудио** — только звук в mp3.

## GitHub Pages

Страница (`index.html`, `app.js`, `style.css`) — статика, её можно выложить на Pages.
Но **скачивание на Pages работать не будет**: Pages не запускает серверный код.
Схема такая: страница живёт на Pages, а кнопка скачивания стучится в `server.py`,
запущенный у тебя на компьютере. Если сервер не запущен, страница покажет
предупреждение, а встроенный плеер для YouTube / X / Reddit продолжит работать.

Папка `downloads` и `.vscode` в репозиторий не попадают (см. `.gitignore`).

## Ограничения

- YouTube и другие сайты иногда меняют защиту — тогда помогает обновление: `python -m pip install -U yt-dlp`.
- Приватные или удалённые посты (X, Reddit) скачать нельзя.
- Только для личного использования.
